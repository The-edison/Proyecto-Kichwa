# Diccionario de datos — Plataforma Kichwa

PostgreSQL. Fuente conceptual: MER v3. Las tablas siguientes coinciden con las migraciones.
No hay columnas UNSIGNED en PostgreSQL. Todas las FK usan ON DELETE RESTRICT.
PK: primaria. FK: foránea. Las fechas usan zona horaria.

## 1. `usuarios`
Cuentas de Administrador y Estudiante; contraseña almacenada únicamente como hash.

| Columna | Tipo PostgreSQL | Restricciones | Descripción |
|---|---|---|---|
| `id_usuario` | `bigint` | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Identificador generado por PostgreSQL. |
| `cedula_usuario` | `varchar(10)` | Admite NULL | Identificación opcional; no se convierte a número. |
| `nombre_usuario` | `varchar(150)` | NOT NULL | Nombres y apellidos. |
| `correo_usuario` | `varchar(254)` | NOT NULL | Correo normalizado en minúsculas y sin espacios exteriores. |
| `contrasena_usuario` | `varchar(255)` | NOT NULL | Hash producido por Laravel Hash; nunca texto plano. |
| `rol_usuario` | `varchar(30)` | NOT NULL DEFAULT 'estudiante' CHECK (rol_usuario IN ('administrador', 'estudiante')) | Perfil único de la cuenta. |
| `estado_usuario` | `varchar(30)` | NOT NULL DEFAULT 'activo' CHECK (estado_usuario IN ('activo', 'bloqueado')) | Habilitación de acceso. |
| `remember_token` | `varchar(100)` | Admite NULL | Soporte técnico opcional de Laravel. |

Restricciones de tabla:
- `UNIQUE (cedula_usuario)`
- `UNIQUE (correo_usuario)`
- `CHECK (correo_usuario = lower(btrim(correo_usuario)) AND position('@' in correo_usuario) > 1)`

## 6. `progreso`
Materialización de avanza: una fila por estudiante y unidad. Estado y porcentaje se consultan en v_progreso.

| Columna | Tipo PostgreSQL | Restricciones | Descripción |
|---|---|---|---|
| `id_progreso` | `bigint` | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Identificador generado por PostgreSQL. |
| `id_usuario` | `bigint` | NOT NULL REFERENCES usuarios (id_usuario) ON DELETE RESTRICT | Referencia a usuarios.id_usuario. |
| `id_unidad` | `bigint` | NOT NULL REFERENCES unidades (id_unidad) ON DELETE RESTRICT | Referencia a unidades.id_unidad. |
| `fecha_inicio_progreso` | `timestamptz` | NOT NULL DEFAULT CURRENT_TIMESTAMP | Primer acceso o primera respuesta a la unidad. |
| `fecha_actualizacion_progreso` | `timestamptz` | NOT NULL DEFAULT CURRENT_TIMESTAMP | Última respuesta registrada; también puede actualizarse al consultar contenidos. |

Restricciones de tabla:
- `UNIQUE (id_usuario, id_unidad)`
- `CHECK (fecha_actualizacion_progreso >= fecha_inicio_progreso)`

## 12. `intentos_evaluacion`
Una realización de una evaluación por un estudiante.

| Columna | Tipo PostgreSQL | Restricciones | Descripción |
|---|---|---|---|
| `id_intento` | `bigint` | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Identificador generado por PostgreSQL. |
| `id_usuario` | `bigint` | NOT NULL REFERENCES usuarios (id_usuario) ON DELETE RESTRICT | Referencia a usuarios.id_usuario. |
| `id_evaluacion` | `bigint` | NOT NULL REFERENCES evaluaciones (id_evaluacion) ON DELETE RESTRICT | Referencia a evaluaciones.id_evaluacion. |
| `numero_intento` | `integer` | NOT NULL CHECK (numero_intento > 0) | Consecutivo por estudiante y evaluación; asignar bajo bloqueo transaccional. |
| `fecha_inicio_intento` | `timestamptz` | NOT NULL DEFAULT CURRENT_TIMESTAMP | Inicio del intento. |
| `fecha_fin_intento` | `timestamptz` | Admite NULL | Fin; NULL mientras está en curso. |
| `estado_intento` | `varchar(30)` | NOT NULL DEFAULT 'en_curso' CHECK (estado_intento IN ('en_curso', 'finalizado', 'abandonado')) | Ciclo de vida del intento. |

Restricciones de tabla:
- `UNIQUE (id_usuario, id_evaluacion, numero_intento)`
- `UNIQUE (id_intento, id_evaluacion)`
- `CHECK ((estado_intento = 'en_curso' AND fecha_fin_intento IS NULL) OR (estado_intento IN ('finalizado','abandonado') AND fecha_fin_intento IS NOT NULL AND fecha_fin_intento >= fecha_inicio_intento))`

## 13. `respuestas_evaluacion`
Una respuesta por pregunta e intento. Dos FK compuestas impiden mezclar evaluaciones.

| Columna | Tipo PostgreSQL | Restricciones | Descripción |
|---|---|---|---|
| `id_respuesta_evaluacion` | `bigint` | GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | Identificador generado por PostgreSQL. |
| `id_intento` | `bigint` | NOT NULL | Parte de FK compuesta a intentos_evaluacion. |
| `id_pregunta` | `bigint` | NOT NULL | Parte de FK compuesta a preguntas. |
| `id_evaluacion` | `bigint` | NOT NULL | Columna técnica compartida por ambas FK; derivar en el backend. |
| `respuesta_evaluacion` | `jsonb` | NOT NULL CHECK (jsonb_typeof(respuesta_evaluacion) = 'object') | Respuesta estructurada enviada. |
| `puntaje_respuesta_evaluacion` | `numeric(8,2)` | NOT NULL CHECK (puntaje_respuesta_evaluacion >= 0) | Puntuación calculada en backend; trigger impide exceder el máximo. |
| `fecha_respuesta_evaluacion` | `timestamptz` | NOT NULL DEFAULT CURRENT_TIMESTAMP | Momento del envío. |

Restricciones de tabla:
- `UNIQUE (id_intento, id_pregunta)`
- `FOREIGN KEY (id_intento, id_evaluacion) REFERENCES intentos_evaluacion (id_intento, id_evaluacion) ON DELETE RESTRICT`
- `FOREIGN KEY (id_pregunta, id_evaluacion) REFERENCES preguntas (id_pregunta, id_evaluacion) ON DELETE RESTRICT`

## 15. Vistas de consulta

No escribir en estas vistas. No duplican datos físicos.

| Vista | Campos añadidos / claves | Regla |
|---|---|---|
| `v_evaluaciones` | Todos los campos de evaluaciones + `puntaje_maximo_evaluacion` NUMERIC(12,2) | Suma de puntajes de preguntas; cero sin preguntas. |
| `v_intentos_evaluacion` | Todos los campos de intentos + `puntaje_obtenido`, `puntaje_maximo_evaluacion`, `calificacion_intento`, `porcentaje_calificacion` | Total obtenido; calificación y porcentaje son NULL hasta finalizar. No contestadas aportan cero. |
| `v_progreso` | Todos los campos de progreso + `total_actividades`, `actividades_completadas` BIGINT, `porcentaje_progreso` NUMERIC, `estado_progreso` VARCHAR(30) | Actividades distintas acertadas / total × 100; unidad vacía = 0, en_curso. |
| `v_progreso_modulos` | `id_usuario`, `id_modulo`, `id_nivel` BIGINT; `porcentaje_progreso_modulo` NUMERIC | Promedio de todas las unidades del módulo; no iniciadas = 0. |
| `v_progreso_niveles` | `id_usuario`, `id_nivel` BIGINT; `porcentaje_progreso_nivel` NUMERIC | Promedio de todas las unidades del nivel, con igual peso por unidad. |
