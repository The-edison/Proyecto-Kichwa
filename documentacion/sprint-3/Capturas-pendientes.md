# Evidencias visuales pendientes

Fecha de revisión: 23 de octubre de 2026, America/Guayaquil. Este archivo complementa el informe y no forma parte del texto académico de la tesis.

Se obtuvieron cinco capturas reales de presentación y consulta pública. No se utilizaron las capturas antiguas de `.verificacion/`, `tmp/` o `documentacion/evidencia/`: no se comprobó su correspondencia con el commit actual ni su ausencia de datos personales. Tampoco se utilizaron los diseños del Sprint 2 como evidencia funcional.

| Pantalla pendiente | Recorrido de la versión revisada | Condición y limitación concreta |
| --- | --- | --- |
| Acceso autenticado y cierre | `/iniciar-sesion` → correo y contraseña de una cuenta de ensayo activa → `/aprender` o `/admin` → cerrar sesión. | Las capturas disponibles muestran el formulario, sin enviar credenciales. El servidor documental admite GET/OPTIONS y utiliza sesiones en memoria; no permite completar el login. Hace falta una instalación de ensayo con sesiones persistentes aisladas y cuentas de prueba. |

No se ejecutó sobre la base existente. Requiere datos educativos de ensayo y padres publicados; para reactivos gestionados, revisión y recursos obligatorios. |
| Edición y versionado | Administrador → contenido utilizado → «Crear nueva versión» → revisar borrador. | Crea registros y puede copiar preguntas; no se ejecutó. Debe prepararse un historial sintético independiente. |

Falta observar el recorrido autenticado. Las primeras cuatro unidades son introducciones sin prácticas; las otras cinco no tienen temas publicados. Los IDs corresponden únicamente a la base consultada. El inventario CSV contiene los títulos para localizar los mismos contenidos cuando los identificadores sean distintos. No se crearon bases, no se migraron esquemas ni se cargaron semillas durante esta revisión.

La comprobación visual de paginación del Word también queda pendiente: la automatización COM falló con `80070520` (sesión de inicio de Windows no disponible). El archivo editable sí se generó y superó la validación estructural ZIP/XML y la comparación de contenido fuera del Sprint 3.
