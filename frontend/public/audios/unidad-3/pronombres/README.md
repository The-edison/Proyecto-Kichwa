# Audios de la Unidad 3: pronombres

Coloca en esta misma carpeta los archivos MP3 con estos nombres exactos. Los seis primeros se escuchan al pulsar cada pronombre en las tarjetas «Una persona» y «Un grupo» de la lección:

| Archivo | Texto que debe escucharse | Significado |
| --- | --- | --- |
| `nuka.mp3` | Ñuka. | Yo. |
| `kan.mp3` | Kan. | Tú. |
| `pay.mp3` | Pay. | Él o ella. |
| `nukanchik.mp3` | Ñukanchik. | Nosotros. |
| `kankuna.mp3` | Kankuna. | Ustedes. |
| `paykuna.mp3` | Paykuna. | Ellos o ellas. |
| `yo-como.mp3` | Ñuka mikuni. | Yo como. |
| `tu-juegas.mp3` | Kan pukllanki. | Tú juegas. |
| `el-duerme.mp3` | Pay puñun. | Él duerme. |

Graba una sola oración por archivo, con voz clara y sin música. Conserva los nombres en minúsculas, sin tildes y con extensión `.mp3`. Solicita la revisión de la pronunciación a una persona hablante de kichwa.

Los ejercicios 3 y 6 reutilizan los tres archivos: el primero pide reconocer el significado y el segundo el pronombre. No se necesita volver a ejecutar las semillas ni cambiar código después de colocar los audios; vuelve a pulsar Escuchar. En desarrollo Vite los sirve desde `/audios/unidad-3/pronombres/`. Para publicar una compilación, vuelve a ejecutar `npm run build` después de añadirlos.
